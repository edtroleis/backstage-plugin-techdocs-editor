# Primeiros passos

Esta página é um exemplo de guia. Experimente editá-la!

## Antes de começar

Você vai precisar de:

- Acesso ao portal
- Uma conta no GitHub com permissão de escrita nesta wiki

## Formatação básica

Você pode usar **negrito**, *itálico*, `código` e [links](../index.md).

| Item     | Descrição                       |
| -------- | ------------------------------- |
| Rascunho | Alterações salvas só para você  |
| Revisão  | Alterações aguardando aprovação |

!!! warning "Atenção"
    Nunca cole senhas, tokens ou dados de clientes na documentação.
