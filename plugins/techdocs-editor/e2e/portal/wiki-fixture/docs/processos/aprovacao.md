# Processo de aprovação

Toda alteração passa por um pull request antes de ser publicada.

## Etapas

1. **Rascunho**: as alterações ficam salvas numa área separada.
2. **Checagens automáticas**: formatação, links e dados sensíveis.
3. **Revisão**: quando exigida, uma pessoa do time aprova.
4. **Publicação**: a página atualizada aparece no portal em alguns minutos.
